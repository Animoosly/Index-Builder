Filename rules and how to use this app
  • 1945-Beryl Avenue Conduit-Profile.pdf → 1945, project “Beryl Avenue Conduit”, description “Profile”.
  • 1949-1952-Alta Loma Storm Drain-History.pdf → start year 1949, end year 1952. The range is preserved.
  • !Misc-Alta Loma Storm Drain-East Alta Loma.pdf → undated, classified as Miscellaneous.
  • 2026-10-21-Project-Report.pdf → a full document date. A year alone never becomes an invented January 1 date.
  • The first segment after the date is the project/location. Remaining hyphen-separated segments form the description. Use Edit when a project name itself contains a hyphen. File modification dates are never used as document dates.
  • Folder selection preserves relative subfolders. Browsers do not expose full local paths for individual files. PDFs are not copied, renamed, embedded, opened, or uploaded. Their content is not parsed or OCRed.
  • Exact repeated selections are skipped using relative path, size, and modification time. Identical file contents under different names are retained. Two files with the same name, size, and timestamp selected individually cannot be distinguished by browser metadata.
  • Download Excel creates a new workbook with a filterable Master Index and optional year tabs. It does not update an existing workbook. Save session downloads a JSON file of your filenames, metadata, and corrections; Load session restores it. Keep your PDFs separately.
  • Example mode contains demonstration filenames only and cannot be mixed with real imports. Clear examples before adding your PDFs. Close or refresh this page only after saving your session if you want to keep your work.
